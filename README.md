# Investment-Portfolio-Dashboard (Excel)

## Overview
This project is an Excel dashboard that analyses the performance of a diversified investment portfolio.

## Features
-Portfolio summary dashboard
-Profit/Loss calculations
-Portfolio allocation by sector
-Current portfolio value analysis
-Interactive charts
-Automatic calculations using Excel formulas

## Skills Demonstrated
-Microsoft Excel
-Financial analysis
-Dashboard design
-Data visualisation
-Formula development 
-Portfolio analysis
